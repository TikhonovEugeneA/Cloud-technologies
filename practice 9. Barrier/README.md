Два потока заполняют свои одномерные численные массивы указанной
пользователем размерности случайными числами. Работа программы
завершается выводом обоих массивов в файл, если каждое число из
первого массива встречается хотя бы раз во втором массиве (либо
наоборот). В противном случае оба потока заново случайно генерируют
численные массивы и т.д.
