**Задание**
1. Создать свой образ Docker с сервером и запустить на его основе контейнер.
2. Проверить работоспособность сервера внутри этого контейнера, внутри
другого контейнера и из браузера базовой ОС.

Сервер отсылает клиенту список файлов в текущей директории и
информацию о количестве символов и строк в каждом файле. Клиент с
помощью специальной команды может запретить/разрешить серверу
отсылать данные о количестве символов и строк в каждом файле.


**Часть теории**
Хост - это IP адрес пк, на котором работает сервер. Для локальной машины это 127.0.0.1. 

Порт - это адрес приложения / сервера. Необходим, так как на одном хосте может работать несколько серверов или сетевых приложений, к которым будут подключаться другие пользователи.

8080:8080 - проброс порта, т.е. открывается порт 8080 на базовой машине и идущие через него данные будут направлены на порт с номером 8080 в контейнере. Иначе порт_хоста:порт_контейнера.

**Использованные команды оболочки sh:**

socat TCP4-LISTEN:8080,reuseaddr,fork SYSTEM:'sh handler.sh'
- TCP4-LISTEN:8080 - прослушивание порта 8080
- reuseaddr - позволяет использовать уже занятый адрес и порт, если он не используется другими процессами. 
- fork - под каждое новое соединение будет обрабатываться в отдельном процессе.
- SYSTEM - запускает выполнять команды или скрипты при установлении соединения. 

read
-r : читает строку ввода, флаг -r игнорирует символ экранирования \ 

grep - поиск 
-c - подсчитывает кол-во строк
-q - выводит статус выхода (0 - совпадение найдено, 1 - совпадение не найдено)

wc - подсчет слов, строк, символов и т.д.
-m - подсчитывает количество символов (включая пробелы и новые строки)

Команды для защиты:
1. Перейти в папку для сборки образа
cd ".\Связь между контейнерами Docker и базовой ОС\"

2. Создать образ 
docker build . -t image3:latest

2. Создать сервер
docker run -it --name server -p 8080:8080 image3

4. Запустить сервер в интерактивном режиме
docker start -i server

5. В другом терминале создать клиент
docker run -it --name client --link=server image3 sh

6. Протестировать работу сервера из его же контейнера
docker exec -it server sh
echo "mode=on" | nc 127.0.0.1 8080

7. Протестировать работу сервера из клиента
docker exec -it client sh
echo "mode=on" | nc server 8080

8. Протестировать работу сервера из браузера базовой ОС
localhost:8080/?mode=on
localhost:8080/?mode=off
